# Why AI Search Can't Understand "Without" | Embeddings Explained

- `word_embeddings.ipynb`: the word map from the video, built from scratch with numpy. It counts which words sit within two places of each word in 68 short sentences, keeps the surprising company (positive PMI), squeezes each word to eight numbers (SVD), compares words by cosine similarity, and draws a flat map (PCA). Add your own sentences and run it again. [Open in Colab](https://colab.research.google.com/github/MhdHabboub/word-embeddings-from-scratch/blob/main/word_embeddings.ipynb)
